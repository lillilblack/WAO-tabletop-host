# WAO 公共触摸屏 · 第一版交互原型

项目位置：`D:\GPTworkspace\WAO新项目\touchscreen`。
这是独立的新主机页面，不调用旧版原创游戏 `server.py`，不修改旧页面。

## 启动

在此目录执行 `python serve.py`，打开 http://localhost:8765 。
也可以在 PowerShell 执行 `./start.ps1`。窗口保持运行，Ctrl+C 停止。

平板体验：执行 `python serve.py --lan`，平板和电脑连接同一可信 Wi-Fi，
用平板打开 `http://电脑的局域网IP:8765`。仅在有需要时允许专用网络防火墙访问，
不要做公网端口映射。默认启动仅本机可访问。

## 体验路径

游戏大厅 → 创建房间 → 人数和计时 → 模拟手环入座 → 开局检查 → 夜间 / 讨论 / 投票 → 再来一局。
支持全屏（取决于浏览器）、暂停计时、公共语音试播、音量、解除绑定、返回确认。
刷新页面清空演示；没有持久化或真实房间。

## 实现边界

- 只设计主机公共屏，未制作手环私密界面。
- 没有真实蓝牙 / NFC / 发牌 / 规则判断 / 投票统计。
- 6 / 9 / 12 人角色数量是界面样例，不能作为已验证的平衡规则。
- 公共页面没有玩家角色映射、夜间行动者名单或个人提交状态。
- 阿瓦隆、谁是卧底仅为未来插件占位，不能开始。
- 浏览器语音依赖系统音色；正式版应提供离线音频。任何声音均仅含公共文案。
- 计时为前端演示计时，结束不自动结算。正式计时以服务器时间与阶段版本为准。

## 后续接入

`model.mjs` 定义页面状态和可允许的演示转换，`app.mjs` 负责渲染。
正式接入时替换本地模拟事件来源，接收经过权限过滤的公共状态；
在服务端验证设备、座位、会话和阶段，禁止把全体私密数据传给公共页面再隐藏。
入座、阶段推进和连接状态需要真实服务回执，不保留演示按钮在正式模式中。
当前模块没有冒充已接入后端的成功提示，连接状态均明确标为模拟。

## 验证

有 Node.js 时运行 `node test.mjs` 验证状态转换与隐私字段边界。
页面采用 Sites 页面设计技能的交互、响应式与可访问性规范；按项目要求仅本地保存，不发布云端。
提供可选 WebMCP 公共状态读取与打开配置入口；当前未在支持该协议的浏览器上下文中验证注册，普通触摸操作不依赖它。未进行浏览器自动点击或截图测试。
